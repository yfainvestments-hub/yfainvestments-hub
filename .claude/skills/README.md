# Web design skills

Claude Code skills for web/UI design work. Each subdirectory is a self-contained
skill (a `SKILL.md` plus supporting files) and loads automatically for Claude Code
sessions run in this repository.

## Skills

| Skill dir | Skill name | What it's for |
|---|---|---|
| `taste-skill` | `design-taste-frontend` | Anti-slop frontend skill for landing pages, portfolios, redesigns |
| `taste-skill-v1` | `design-taste-frontend-v1` | Preserved v1 of the taste skill |
| `soft-skill` | `high-end-visual-design` | Agency-grade fonts, spacing, shadows, cards, motion |
| `minimalist-skill` | `minimalist-ui` | Clean editorial monochrome interfaces |
| `brutalist-skill` | `industrial-brutalist-ui` | Raw Swiss/terminal brutalist interfaces |
| `redesign-skill` | `redesign-existing-projects` | Audit + upgrade existing sites/apps to premium |
| `brandkit` | `brandkit` | Brand-guideline boards, logo systems, identity decks |
| `stitch-skill` | `stitch-design-taste` | DESIGN.md generation for Google Stitch |
| `imagegen-frontend-web` | `imagegen-frontend-web` | Website design reference image generation |
| `imagegen-frontend-mobile` | `imagegen-frontend-mobile` | Mobile app screen concept generation |
| `image-to-code-skill` | `image-to-code` | Design-image → code workflow |
| `gpt-tasteskill` | `gpt-taste` | UX/UI + GSAP motion engineering (GPT/Codex-oriented) |
| `output-skill` | `full-output-enforcement` | Prevents truncated/placeholder code output |
| `impeccable` | `impeccable` | Design/redesign/critique/polish design-language skill |
| `playwright-cli` | `playwright-cli` | Browser automation to verify designs in a real browser |
| `img2threejs` | `img2threejs` | Turn a reference image into a procedural Three.js model |
| `awesome-design-md` | `awesome-design-md` | Decoded design systems for 70+ real brands (reference) |
